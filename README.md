# Kestrel Studio

Clear product thinking for ambitious teams.

Live: https://kestrel-studio.vercel.app

## What it is

Kestrel Studio is a digital partner for ambitious teams, helping turn complex business challenges into clear, capable digital products. This site is a high-performance landing page focused on our process, principles, and capabilities.

## Stack

- Framework: Next.js 16 (App Router)
- UI: React 19, TypeScript
- Motion: GSAP 3, Lucide Icons
- Styling: Tailwind CSS 4
- Fonts: Space Grotesk, IBM Plex Mono

## Getting started

Requirements: Node.js 20.9+ and pnpm.

```bash
pnpm install
pnpm dev
```

## Scripts

| Command | Purpose |
| --- | --- |
| `pnpm dev` | Development server |
| `pnpm build` | Production build |
| `pnpm lint` | ESLint |
| `pnpm typecheck` | TypeScript validation |
